## วิธีการทำงาน (Workflow)

1. Fork หรือ clone repository นี้ (ตามที่ผู้สอนกำหนด)
2. เข้าไปที่โฟลเดอร์ของกลุ่มตนเอง แล้วแก้ไข `README.md` ตามโครงสร้างใน `rust_tutorial_template.md`
3. Commit และ Push งานของกลุ่ม แล้วเปิด Pull Request มาที่ branch `main`
4. สมาชิกในกลุ่มช่วยกัน Review และแก้ไขจนโค้ดทุกตัวอย่าง compile/run ได้จริง
5. ผู้สอน/ผู้ช่วยสอน จะ Merge หลังตรวจสอบ
